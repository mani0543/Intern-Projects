# Intern-Projects


## 🚀 Projects Overview

The repository is organized into the following main directories:

### 1. 📝 Text-Classifier
A robust natural language processing (NLP) application designed to accurately categorize text data into predefined classes. It is useful for tasks like sentiment analysis, topic labeling, or spam detection.
* **Directory:** `Text-Classifier/`
* **Live Demo:** [Hugging Face Space - Text Classifier](https://huggingface.co/spaces/Mani890/text-classifier)

### 2. 📄 Resume Screening
An automated tool built to streamline HR workflows. This application parses uploaded resumes (PDF/Docx), extracts key skills, experience, and educational background, and evaluates them against specific job roles.
* **Directory:** `Resume Screening/`
* **Live Demo:** [Hugging Face Space - Resume Screening](https://huggingface.co/spaces/Mani890/screening-of-resume)

### 3. 🤖 Chatbot - My zeroAI
An interactive conversational AI companion powered by deep learning models. It handles user queries dynamically, maintaining context to simulate seamless human-like interactions.
* **Directory:** `Chatbot-My zeroAI/`
* **Live Demo:** [Hugging Face Space - ZeroAi](https://huggingface.co/spaces/Mani890/ZeroAi)

---

## 🛠️ Tech Stack & Prerequisites

Most applications in this repository are built using modern open-source AI frameworks:
* **Frontend/UI:** Streamlit / Gradio
* **Backend:** Python
* **Deployment:** Hugging Face Spaces
