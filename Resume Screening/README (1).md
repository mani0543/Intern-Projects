# 📄 Resume Screening System

Automatically screen and rank resumes against job descriptions using keyword matching and skill extraction.

## Features

- 📄 Upload PDF, DOCX, TXT files
- 🔍 Extract and analyze text automatically
- 📊 Calculate match scores based on keywords
- 🎯 Extract relevant skills from resumes
- 📈 Interactive visualizations and charts
- 💾 Download results as CSV

## How to Use

1. **Paste Job Description** - Enter the job requirements in the left panel
2. **Upload Resumes** - Upload one or multiple resume files
3. **Review Results** - View ranked candidates with match scores
4. **Adjust Settings** - Modify skills database or threshold in sidebar
5. **Export Data** - Download results for further analysis

## Technical Details

- Built with Streamlit
- Supports PDF, DOCX, and TXT formats
- Uses keyword matching for scoring
- No external API calls needed
